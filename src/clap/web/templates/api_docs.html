CLAP Web 接口

所有模型调用都经由 provider 层，端点是 OpenAI 兼容的 HTTP API； 凭证只从环境变量（*_API_KEY / *_TOKEN / *_KEY）、 ~/.config/opencode/opencode.json、~/.pi/agent/auth.json 内存读取， 接口只返回掩码。

对话与模型

方法路径说明
GET/api/models 按 provider 分组的模型清单；含环境变量装配结果（env_assembly）、掩码凭证、可用性与默认选择。
POST/api/chat SSE 流式对话。请求体 {"message","provider","model","branch","lane","grounded","zims","top_k","renew_summary"}； 事件依次为 start →（有依据模式）sources → 若干 delta → done （含延迟、token 用量、来源清单、逐句审计 audit、错误）。 有依据模式：先检索 ZIM，材料为空时直接弃答「来源未提及」。
POST/api/chat/stop 暂停流（对话暂停）。请求体 {"stream_id"}，留空则暂停当前全部在跑流； 已生成文本保留，会话中记为 error:"cancelled"。

会话

方法路径说明
GET/api/session/get 当前内存会话：主线消息、分支、标注、隐私切换记录。
POST/api/session/new新建空会话。
POST/api/session/save 保存为 v2 .clap。请求体 {"path"}。
POST/api/session/load 加载 .clap（v1 自动无损迁移）。请求体 {"path"}。
POST/api/session/fork 在某条消息处分叉。请求体 {"at","name","model","note"}。
POST/api/session/export 导出当前分支。请求体 {"format":"md|html|json","branch","path"}； 返回 content 与已写入的 path。HTML 零外链。
POST/api/session/share 打包为 .clapshare（不含密钥与本机路径）。
POST/api/session/adopt 导入分享包。请求体 {"package","policy":"rename|overwrite|fork"}。
POST/api/session/renew 会话续期：生成确定性摘要（消息数、轮次、标注要点），返回 summary； 下一条对话把它作为 system 桥接消息携带。

ZIM 外置知识库（有依据模式）

方法路径说明
GET/api/zim/list 列出 CLAP_ZIM_ROOTS（默认 ~/Documents/重点文献）下的 ZIM：条目数、体积、语言、可读性。
POST/api/zim/search {"query","zims","top_k"} → 命中 [{zim,path,title,snippet,score}]。
GET/api/zim/article?zim=&path= 读取原文（HTML→纯文本），用于引用面板与阅读器。
POST/api/zim/suggest 标题补全。请求体 {"prefix","zim","limit"}。

标注

方法路径说明
POST/api/annotate 请求体 {"target","kind","tags","note","author"}； kind 取 keypoint / question / generated / reviewed / error_fix / knowledge_point。
POST/api/annotate/export 导出 CSV/JSON。请求体 {"path","format"}。

知识库

方法路径说明
POST/api/kb/indexmultipart 上传文件并入库。
POST/api/kb/search{"query","k"} 检索。
GET/api/kb/stats库状态（分块数、目录）。
POST/api/kb/clear清空知识库。

页面

方法路径说明
GET/对话页（默认落地页）：有依据模式、分支、标注、导出/分享/续期。
GET/kb知识库页：ZIM 库列表、检索、原文阅读、分享包导入。
GET/timeline?file=…时间轴视图，渲染指定 .clap 会话。
GET/api-docs本页。
默认地址 127.0.0.1:5057（5000 端口在 macOS 上被 AirPlay 占用）。
